# Forest visual reference

`living-forest-reference.mp4` is the user-supplied visual reference received on
2026-09-05. Keep it in this folder as the durable art-direction source for future
Forest Friends work.

The current scene also uses it directly as a silent, looping background. Its key
visual cues are:

- portrait storybook composition with a winding blue river;
- layered foreground, midground forest and distant hills;
- warm autumn accents among predominantly green foliage;
- small ambient motions that make the illustration feel alive without competing
  with the animals or controls.

When the UI is changed later, preserve the calm storybook tone, legible open
clearings and restrained motion established by this reference.
